    Plex server
    How to reach the server Automatic asks plex.tv where your server is each time the app checks, so it works at home and away. Away from home it needs Remote Access switched on in Plex.

    Android app

    Get the Android app

    Opens the latest release on GitHub. Download the .apk file there and open it on the phone. It installs over the app you already have and keeps its data.

    Watchlist

    Uses the same token against plex.tv. Removing an item in the app removes it from Plex, and removing it in Plex removes it here.

    On start, the app quietly redoes the fast half of Check for updates: your library, watchlist, episode schedules and film dates. It skips the slow MusicBrainz step, so the dashboard is current within a couple of minutes without a long wait.
